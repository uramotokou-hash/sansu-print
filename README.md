# 算数プリント自動生成メーカー

学年と計算の型をえらぶだけで、日付入りの計算プリント（A4・PDF）を作れる無料Webアプリです。
帯活動や知的学級での反復練習に使えるよう、何日分かをまとめて作れます。

公開ページ：https://uramotokou-hash.github.io/sansu-print/

## できること（v0.1）

- 学年 → 計算の型 → むずかしさ（くり上がり・くり下がり・あまり など）の順にえらぶ
- 1日の問題数・日数を指定して、日付入りのプリントを1つのPDFにまとめて出力
  - 日付は「自動で入れる」か「空欄（手書き）」。土日をとばせる
  - 問題の出し方：毎日ちがう／くり返し／少しずつ入れかえ
- レイアウト：1日1枚／1枚に何日分も（入る日数は問題の大きさから自動で計算）
- 横式・筆算（1マス1数字）。筆算はメモマス・位のガイドをオン/オフ
- 手ごたえマーク（顔3つに丸をつける）、かかった時間の欄
- 答えのページを最後に自動でつける（赤字）
- 設定はURLに入るので、リンクを共有すれば同じプリントを作れる
- 入力した内容は端末の中だけで使い、サーバーには送らない

## 収録している計算の型

| 学年 | 型 |
|---|---|
| 1年 | 10までのたし算／10までのひき算／たし算（1けた＋1けた）／ひき算（十いくつ−1けた）／3つの数の計算 |
| 2年 | 2けた＋2けた／2けた−2けた／3けた＋2けた（かんたん）／百いくつ−2けた／九九 |
| 3年 | 3けた・4けたのたし算／3けた・4けたのひき算／2けた・3けた×1けた／2けた×2けた／わり算（九九1回） |
| 4年 | 2けた・3けた÷1けた／2けた・3けた÷2けた |

次の版で追加予定：小数（3〜5年）、分数（3〜6年）、6年の四則混合、わり算の筆算。

## ファイル構成

- `index.html` … 画面
- `js/generators.js` … 問題の生成（計算の型の一覧はここ）
- `js/layout.js` … A4ページの組み立て
- `js/app.js` … 画面の動き・URL共有・PDF出力
- `css/print.css` … プリントの見た目、`css/app.css` … 画面の見た目
- `tests/generators.test.js` … 全型・全条件で答えと条件を確かめるテスト（`node tests/generators.test.js`）
