# 算数プリント自動生成メーカー

学年と計算の型をえらぶだけで、日付入りの計算プリント（A4・PDF）を作れる無料Webアプリです。
帯活動や知的学級での反復練習に使えるよう、何日分かをまとめて作れます。

公開ページ：https://uramotokou-hash.github.io/sansu-print/

## できること（v1.0）

- 学年 → 計算の型 → むずかしさ（くり上がり・くり下がり・あまり・約分 など）の順にえらぶ
- 1日の問題数・日数を指定して、日付入りのプリントを1つのPDFにまとめて出力
  - 日付は「自動で入れる」か「空欄（手書き）」
  - 算数がある曜日をえらべる。日付の一覧から、算数がない日をタップしてとばせる
  - 問題の出し方：毎日ちがう／くり返し／少しずつ入れかえ
- レイアウト：1日1枚／1枚に何日分も（入る日数は問題の大きさから自動で計算）
- 横式・筆算（1マス1数字）。小数の筆算は小数点をマスの間の下に打つ。答えの最後の0には斜線
- わり算の筆算（整数・小数）。答えのページでは、動かしたあとの小数点を赤で示す
- 分数は縦の形で表示。答えは約分した形で、帯分数になるときは仮分数も（ ）で示す
- 分数の「途中の式」の欄（5年は最初からオン）
- 手ごたえマーク（顔とことば／ことばだけ／なし）。ことばは すらすら・いけそう・ちょっとふあん・しんぱい・むずかしい からえらぶ
- かかった時間の欄、答えのページ（赤字）
- 自分で問題を入れる：式を1行に1つずつ入れると、答えを自動で計算してプリントにする（整数・小数・分数、（ ）1組まで）
- 設定はURLに入るので、リンクを共有すれば同じプリントを作れる
- 入力した内容は端末の中だけで使い、サーバーには送らない

## 収録している計算の型（39種類＋自分で問題を入れる）

| 学年 | 整数 | 小数・分数 |
|---|---|---|
| 1年 | 10までのたし算・ひき算／たし算（1けた＋1けた）／ひき算（十いくつ−1けた）／3つの数の計算 | |
| 2年 | 2けた＋2けた／2けた−2けた／3けた＋2けた（かんたん）／百いくつ−2けた／九九 | |
| 3年 | 3けた・4けたのたし算・ひき算／2けた・3けた×1けた／2けた×2けた／わり算（九九1回） | 小数のたし算・ひき算（1/10の位）／分数のたし算・ひき算（分母が同じ） |
| 4年 | 2けた・3けた÷1けた／2けた・3けた÷2けた（筆算可） | 小数のたし算・ひき算（1/100の位）／小数×整数／小数÷整数／分数のたし算・ひき算（分母が同じ・1より大きい） |
| 5年 | | 小数×小数／小数÷小数（わり切れる・四捨五入・あまり）／分数のたし算・ひき算（分母がちがう） |
| 6年 | 四則混合（計算のきまり） | 分数×整数／分数÷整数／分数×分数／分数÷分数／帯分数のかけ算・わり算／分数・小数・整数のまじった計算（×÷） |

学年は目安です（教科書会社によって扱う学年が前後する型があります）。

## ファイル構成

- `index.html` … 画面
- `js/generators.js` … 問題の生成（計算の型の一覧はここ）と、分数で正確に計算する検算
- `js/layout.js` … A4ページの組み立て（筆算・分数・日付）
- `js/app.js` … 画面の動き・URL共有・PDF出力
- `css/print.css` … プリントの見た目、`css/app.css` … 画面の見た目
- `tests/generators.test.js` … 全型・全条件で答えと条件を確かめるテスト（`node tests/generators.test.js`）
